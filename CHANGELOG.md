# Change Log

All notable changes to the "openrouter-usage" extension will be documented in this file.

## 0.0.1

- Secure API and optional management-key storage using VS Code SecretStorage.
- Status-bar spending cap alerts and an Explorer usage panel.
- All-time, daily, weekly, monthly, BYOK, and available free-model request usage.
- Optional account balance, automatic refresh, retry cooldowns, and stale-data indicators.
- Unit and extension-host tests; local VSIX packaging.
